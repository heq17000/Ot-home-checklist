# 우리집 안전점검

## 소개
이 프로젝트는 작업치료 관점에서 집 안의 위험요소를 찾아보고, 어르신의 일상생활을 더 안전하게 만드는 주거환경 개선 방법을 배울 수 있는 웹 게임입니다.

## 주요 기능
- 주거 유형을 선택하고 6개 공간의 위험요소를 점검하는 기능
- 개선 전/후 이미지를 통해 환경수정과 보조도구 적용을 확인하는 기능
- 실제 우리집 체크리스트, 결과 요약, 설문조사, 관련 정보 연결 기능

## 사용 방법
1. 파일을 다운로드합니다.
2. `index.html` 파일을 브라우저에서 실행합니다.
3. 게임방법을 확인한 뒤 우리집 유형을 선택합니다.
4. 사진 속 점검해야 하는 부분을 터치하며 6개 공간을 확인합니다.
5. 체크리스트와 결과 화면에서 우리집 위험군을 확인합니다.
